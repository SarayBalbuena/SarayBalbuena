## 🪂 Featured project: Wind Tunnel Logbook

A full-stack app for tracking indoor skydiving (wind tunnel) flight time: individual, coaching and shared sessions, plus reports on your progress.

| Repo | What it is | Stack |
| --- | --- | --- |
| [wind-tunnel-registry-frontend](https://github.com/SarayBalbuena/wind-tunnel-registry-frontend) | Dashboard with Google sign-in, protected routes, and light/dark mode | React 19 · TypeScript · Vite · Chakra UI v3 · SWR · Biome |
| [wind-tunnel-registry-backend](https://github.com/SarayBalbuena/wind-tunnel-registry-backend) | REST API with Google OAuth2 + JWT, flight entries, bulk import, reports, and Swagger docs | NestJS 11 · MongoDB · Vitest · Docker · Koyeb |
